# 🚌 Sitio Web Oficial de FONTUR (Fundación Fondo Nacional de Transporte Urbano) Bienvenido al repositorio del portal web institucional de la **Fundación Fondo Nacional de Transporte Urbano (FONTUR)**, ente adscrito al Ministerio del Poder Popular para el Transporte de la República Bolivariana de Venezuela. 🔗 **URL del Sitio:** [http://www.fontur.gob.ve/](http://www.fontur.gob.ve/) --- ## 📋 Tabla de Contenidos - [Acerca del Proyecto](#-acerca-del-proyecto) - [Características Principales](#-características-principales) - [Stack Tecnológico](#-stack-tecnológico) - [Estructura del Proyecto](#-estructura-del-proyecto) - [Requisitos Previos](#-requisitos-previos) - [Instalación y Configuración](#-instalación-y-configuración) - [Sedes Regionales](#-sedes-regionales) - [Contacto y Soporte](#-contacto-y-soporte) --- ## ℹ️ Acerca del Proyecto El portal de **FONTUR** sirve como la plataforma centralizada de información, atención al ciudadano y gestión de servicios orientados a transportistas y usuarios del sistema de transporte público nacional en Venezuela. Entre sus funciones principales destacan el registro de flotas, gestión de subsidios, venta/distribución de repuestos y atención a las sedes regionales en todo el país. --- ## ✨ Características Principales * 🗞️ **Noticias e Información Institucional:** Secciones dedicadas a las últimas notas de prensa, comunicados oficiales y programas de la institución. * 💳 **Gestión de Servicios al Transportista:** Información de registro, carnets y acceso a sistemas de subsidio o pasaje estudiantil. * 🗺️ **Directorio de Sedes Regionales:** Listado exhaustivo de oficinas operativas distribuidas en los 23 estados y el Distrito Capital. * 📑 **Descarga de Formatos y Requisitos:** Guías de trámites y formularios para la solicitud de repuestos, repotenciación e insumos. * 📱 **Diseño Responsivo:** Adaptabilidad a dispositivos móviles, tablets y monitores de escritorio. --- ## 🛠️ Stack Tecnológico | Capa | Tecnología | Descripción | | :--- | :--- | :--- | | **CMS / Backend** | WordPress (PHP) | Sistema de gestión de contenidos y lógica del servidor | | **Frontend** | HTML5, CSS3, JavaScript | Interfaz de usuario personalizada, estilos y dinamismo visual | | **Base de Datos** | PostgreSQL | Almacenamiento relacional de trámites, publicaciones y datos del portal | | **Servidor Web** | Apache / Nginx | Servidor web HTTP para entornos PHP | --- ## 📁 Estructura del Proyecto ```text fontur-web/ ├── wp-content/ │ ├── themes/ │ │ └── fontur-theme/ # Tema personalizado de WordPress (PHP, CSS, JS) │ └── plugins/ │ └── fontur-custom/ # Funcionalidades e integraciones específicas ├── data/ │ └── sedes_fontur.json # Datos estructurados de sedes regionales └── README.md # Documentación general ``` --- ## ⚙️ Requisitos Previos Asegúrate de contar con los siguientes componentes en tu entorno local o servidor: - **PHP:** Versión 8.0 o superior con extensiones activas para PostgreSQL (`pdo_pgsql`, `pgsql`). - **Base de Datos:** PostgreSQL v12.0 o superior. - **CMS:** WordPress v6.0 o superior. - **Servidor Web:** Apache / Nginx. --- ## 🚀 Instalación y Configuración 1. **Clonar el repositorio:** ```bash git clone https://github.com/tu-usuario/fontur-web.git cd fontur-web ``` --- ## 🏢 Sedes Regionales La plataforma incluye información detallada y ubicación geográfica de las sedes de FONTUR en todo el territorio nacional, facilitando la atención descentralizada. --- ## 📞 Contacto y Soporte -
